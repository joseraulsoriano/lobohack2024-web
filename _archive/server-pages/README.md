# Páginas con backend (archivadas)

Rutas que requerían API Elysia, Postgres y auth (`auth-astro`):

- `/api/*`
- `/acceder`
- `/equipos/*`
- `/usuarios/*`

El despliegue en Vercel es **solo front estático** (landing `index.astro`). Para registro y operación usa el monorepo `aweb` + `api-hack` + `hack-app`.
